# KITSTREAM - Plataforma de Venta de Streaming y Catálogo VIP

Plataforma web comercial y catálogo interactivo de suscripciones de streaming (Netflix, Disney+, Max, Spotify, IPTV, etc.) con entrega inmediata vía WhatsApp.

## 🚀 Características
- **Identidad KITSTREAM**: Barra de navegación temática interactiva con destello neón y estética ciberpunk.
- **Catálogo de Cuentas & Pantallas**: Perfiles privados con PIN y cuentas completas familiares.
- **Multidivisa en Tiempo Real**: Soporte para USD, MXN, COP, ARS y EUR.
- **Combos VIP & Descuentos**: Paquetes especiales para maximizar el ahorro.
- **Calculadora Interactiva de Ahorro**: Comparativa de costo oficial vs KITSTREAM.
- **Checkout directo a WhatsApp**: Carrito de compras con resumen formateado para confirmación inmediata.
- **Garantía y Métodos de Pago**: Binance USDT, transferencias bancarias locales, Yape, Plin, Nequi, SPEI, PayPal y tarjetas.

## 📁 Estructura del Proyecto
- `index.html` — Página principal, catálogo comercial y checkout.
- `catalogo.html` — Vista demo de catálogo y streaming en vivo.
- `login.html` — Portal de acceso a terminales.

## 👥 Colaboración en Equipo
1. Clona el repositorio:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   ```
2. Trabaja en tus cambios.
3. Antes de subir cambios, actualiza tu copia local:
   ```bash
   git pull origin main
   ```
4. Guarda y sube tus cambios:
   ```bash
   git add .
   git commit -m "Descripción de los cambios"
   git push origin main
   ```
